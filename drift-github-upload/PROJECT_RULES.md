# Drift Project Rules

## Purpose

Reduce anxiety and create emotional breathing room.

## Must Feel

- Calm
- Spacious
- Human
- Non-clinical

## Must Never Become

- Task manager
- Habit tracker
- Streak app
- Productivity system
- Therapy worksheet

## Writing Style

- Short
- Simple
- Human
- Say less when unsure

Avoid:

- "hold space"
- "journey"
- "honor your feelings"
- "meet yourself where you are"
- AI wellness language
- Productivity language

## Interaction Principles

- Release pressure
- Create space
- Allow pause

## Core Flow

Hold  
Release  
Choose  
Rest
